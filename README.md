# 🛒 Projeto Banco de Dados – E-commerce

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como parte de um desafio da DIO com o objetivo de replicar a modelagem lógica de um banco de dados para um cenário de e-commerce.

Foi realizado:

- Criação do esquema do banco de dados
- Definição de chaves primárias e estrangeiras
- Aplicação de constraints
- Inserção de dados para testes
- Desenvolvimento de consultas SQL

---

## 🎯 Refinamentos Aplicados

- Cliente pode ser Pessoa Física (PF) ou Pessoa Jurídica (PJ), mas não ambos
- Cliente pode possuir múltiplas formas de pagamento
- Pedido possui status de entrega e código de rastreio

---

## 🔎 Consultas SQL

Foram desenvolvidas queries contendo:

- SELECT simples
- Filtros com WHERE
- Ordenações com ORDER BY
- Atributos derivados
- Agrupamentos com HAVING
- Junções entre tabelas (JOIN)

Exemplos de perguntas respondidas:

- Quantos pedidos cada cliente realizou?
- Existe vendedor que também é fornecedor?
- Relação entre produtos, fornecedores e estoques

---

## 🚀 Como Executar

1. Execute o script de criação do banco
2. Execute o script de inserção de dados
3. Execute o script com as consultas SQL

Projeto desenvolvido para fins educacionais como parte do desafio da DIO.
